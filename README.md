# روزنه | Rozaneh 0.5.0

[دانلود نسخهٔ اصلی](https://github.com/Grandudelife/Rozene/archive/refs/heads/main.zip)

افزونهٔ متن‌باز Chrome برای هدایت ترافیک ابزارهای گوگل به Tor یا پروکسی محلی انتخاب‌شده؛ با رابط فارسی و بدون مرحلهٔ build.

## تغییرات ۰.۵.۰

- دکمه‌های Gemini، Flow، **AI Studio** و Notebook ابتدا مسیر اتصال را فعال و مالکیت پروکسی را بررسی می‌کنند، سپس سایت را باز می‌کنند. نسخهٔ قبلی حتی با روزنهٔ خاموش سایت را باز می‌کرد.
- انتخاب Tor، SOCKS5 محلی یا HTTP محلی برای استفاده از خروجی VPN یا تونل SSH فراهم است. میزبان همیشه `127.0.0.1` است.
- تنظیم معتبر نسخهٔ ۰.۴.۱ پس از ارتقا همچنان شناسایی می‌شود؛ تغییر پورت و نوع مسیر فقط در حالت خاموش انجام می‌شود.
- نتیجهٔ آزمایش یک پروکسی معمولی با «Tor تأیید نشد» اشتباه گرفته نمی‌شود.

**روزنه IP یا کشور خروجی تولید نمی‌کند.** کشور واقعی به Tor، VPN یا تونلی که به آن وصل می‌شوید بستگی دارد. روشن‌بودن VPN یا دریافت `IsTor:true` به معنی پذیرش اتصال توسط Gemini نیست. تغییر زبان، ساعت یا DNS به‌تنهایی کشور IP را تغییر نمی‌دهد.

## نصب و استفاده

1. ZIP را استخراج کنید؛ پوشه‌ای که `manifest.json` مستقیماً در آن است نگه دارید.
2. در `chrome://extensions`، Developer mode → Load unpacked را بزنید و همان پوشه را انتخاب کنید.
3. در روزنه «تنظیم مسیر اتصال» را باز کنید. برای Tor Browser، نوع Tor و پورت `9150` را انتخاب کنید؛ Tor باید روی همین کامپیوتر باز و متصل باشد.
4. برای پروکسی یک VPN یا SSH، نوع SOCKS5 یا HTTP و پورت واقعی برنامهٔ محلی را انتخاب کنید. **WireGuard به‌تنهایی پورت SOCKS5/HTTP ندارد**؛ پورت تونل UDP آن را اینجا وارد نکنید.
5. مسیر را فعال و اتصال را آزمایش کنید، سپس سرویس را باز کنید. کلیک روی هر دکمهٔ سرویس در حالت خاموش هم ابتدا مسیر انتخاب‌شده را فعال می‌کند.
6. در Gemini یک پاسخ واقعی، در AI Studio دسترسی به محیط ساخت prompt، و در Flow دسترسی به محیط پروژه را بررسی کنید. تولید محتوا و سهمیه‌ها در کنترل گوگل‌اند.

برای ارتقای افزونهٔ unpacked موجود، فایل‌های جدید را در همان پوشه جایگزین کنید و در `chrome://extensions` دکمهٔ Reload را بزنید. نشست و حساب گوگل نیاز به حذف ندارند. افزونه مجوز جدیدی درخواست نمی‌کند.

## خطای کشور با وجود VPN یا Tor

در بررسی ۴ اکتبر ۲۰۲۶، خطای منطقه‌ای Gemini با مسیر Tor فعال بازتولید شد. تنظیم محلی به یک خروجی ثابت وابسته بود. چند مدار Tor با خروجی آمریکا نیز HTTP 403 گرفتند؛ بعضی خروجی‌های کشورهای پشتیبانی‌شده پاسخ HTTP 200 دادند. این نتیجه نشان می‌دهد انتخاب یک کشور کافی نیست و پذیرش IP خروجی هم باید آزمایش شود. HTTP 200 صفحهٔ عمومی، به‌تنهایی موفقیت ورود و دریافت پاسخ را اثبات نمی‌کند.

پس از انتخاب خروجی پذیرفته‌شده، نسخهٔ ۰.۵.۰ روی Chrome مک بارگذاری شد: Gemini با حساب واقعی پاسخ آزمایشی داد، کشور «Germany — From your IP address» را نمایش داد و محیط AI Studio و فهرست پروژه‌های Flow هم باز شدند. تولید پولی آزمایش نشد. این خروجی اختصاصیِ آزمایش در بستهٔ عمومی قرار ندارد.

راهنمای قدیمی یک IP خروجی مشخص را توصیه می‌کرد؛ آن توصیه حذف شده است. هیچ خروجی عمومی Tor برای همیشه کار نمی‌کند و افزونه نمی‌تواند کشور Tor را از طریق API پروکسی Chrome انتخاب یا مدار آن را عوض کند.

مسیر پیشنهادی برای استفادهٔ روزانه، یک خروجی ثابت و قابل‌اعتماد در کشور پشتیبانی‌شده است که Google آن را بپذیرد. خروجی آمریکا هم ممکن است به دلیل اعتبار IP مسدود شود. اگر VPN فعلی پورت محلی ندارد، می‌توان از VPN با پروکسی محلی یا تونل SSH روی سرور خودتان استفاده کرد:

```sh
ssh -N -D 127.0.0.1:1080 USER@YOUR_SERVER
```

این دستور فقط با سرور و دسترسی SSH خودتان کار می‌کند؛ روزنه سرور یا اشتراک فراهم نمی‌کند. بررسی کلید میزبان SSH را فعال نگه دارید. پس از اتصال، در روزنه SOCKS5 و پورت 1080 را انتخاب کنید. WireGuard متصل می‌تواند برای اتصال به Tor یا سرور SSH باز بماند.

برای Tor، تنظیم خروجی در فایل `torrc` متعلق به خود Tor است. ابتدا از فایل پشتیبان بگیرید؛ به‌جای IP قدیمی می‌توانید یک مجموعهٔ کشور پشتیبانی‌شده را آزمایش کنید، مثلاً `ExitNodes {de},{nl},{gb},{ca}` یا برای آزمایش آمریکا `ExitNodes {us}`. یک خط ExitNodes داشته باشید. محدودکردن خروجی، انتخاب مدار را محدود می‌کند و این پروژه برای ناشناس‌ماندن طراحی نشده است. تنظیم کشور تضمین پذیرش IP یا کشور تشخیص‌داده‌شدهٔ گوگل نیست.

پس از تغییر خروجی، اتصال‌های قدیمی Chrome ممکن است برقرار بمانند. کارهای ذخیره‌نشده را ذخیره کنید و Chrome را کامل ببندید و دوباره باز کنید؛ Tor یا پروکسی باز بماند. «New Circuit for this Site» در Tor Browser الزاماً مدار Chrome را تغییر نمی‌دهد.

شرایط منطقه و حساب هر سرویس مستقل‌اند: [Gemini](https://support.google.com/gemini/answer/13575153?hl=en)، [AI Studio](https://ai.google.dev/gemini-api/docs/available-regions)، [Flow](https://support.google.com/flow/answer/16353333?hl=en). در AI Studio، سن یا تأیید سن حساب نیز می‌تواند علت رد دسترسی باشد.

## دامنهٔ اثر و حریم خصوصی

ریشه‌های `google.com`، `googleapis.com`، `gstatic.com`، `googleusercontent.com` و `ggpht.com` و زیردامنه‌هایشان، و میزبان‌های دقیق `labs.google`، `accounts.youtube.com` و `check.torproject.org` از پروکسی انتخابی عبور می‌کنند. Gmail و Drive هم تحت‌تأثیر قرار می‌گیرند. دامنه‌های دیگر `DIRECT` هستند؛ این به معنی استفاده از مسیر شبکهٔ سیستم است و VPN سیستم می‌تواند روی آن‌ها اثر داشته باشد. قواعد پروکسی پیشین سیستم هنگام فعال‌بودن PAC روزنه برای این مقصدها اعمال نمی‌شوند.

برای مقصدهای انتخابی، مسیر مستقیم جایگزین وجود ندارد. اگر پروکسی خاموش شود، این مقصدها خطا می‌دهند. خاموش‌کردن روزنه فقط تنظیم خود افزونه را پاک می‌کند و کنترل را به Chrome/سیستم برمی‌گرداند. روزنه در Incognito فعال نیست.

مجوزها همان `proxy` و `storage`، با دسترسی فقط به سرویس بررسی Tor هستند. متن گفتگو، کوکی، رمز، تاریخچه و محتوای صفحات خوانده نمی‌شوند؛ IP پاسخ سرویس بررسی وارد گزارش نمی‌شود. پروکسی و مقصد نهایی IP اتصال را می‌بینند. هیچ گواهی نصب یا پاسخ Google تغییر داده نمی‌شود.

این مسیر تمام ترافیک دستگاه، WebRTC یا همهٔ سیگنال‌های موقعیت را پوشش نمی‌دهد. اتصال Chrome به Tor، محافظت‌های Tor Browser را به Chrome اضافه نمی‌کند. [توضیح Tor](https://support.torproject.org/tor-browser/security/using-tor-with-other-browsers/)

## عیب‌یابی

| وضعیت | اقدام |
| --- | --- |
| کنترل پروکسی در اختیار روزنه نیست | افزونهٔ پروکسی رقیب یا سیاست مدیریتی را بررسی کنید؛ روزنه آن‌ها را خودکار غیرفعال نمی‌کند. |
| Connection refused | پورت محلی، نوع پروکسی و روشن‌بودن برنامهٔ آن را بررسی کنید. پورت کنترل Tor مثل 9151 مناسب نیست. |
| آزمایش اتصال کامل نشد | سرویس بررسی یا مسیر ممکن است پاسخ نداده باشد؛ این نتیجه به‌تنهایی قطعی Tor را اثبات نمی‌کند. |
| آزمایش موفق، ولی خطای کشور یا 403 | خروجی مورد قبول Google، اتصال تازه و شرایط حساب همان سرویس را بررسی کنید. |
| گزارش check خالی | حافظهٔ سرویس پس‌زمینه ممکن است خوابیده باشد؛ آزمایش را تکرار کنید. |

برای بررسی دستی Tor:

```sh
curl -q --noproxy '' --proxy socks5h://127.0.0.1:9150 --connect-timeout 10 --max-time 30 --fail --silent --show-error https://check.torproject.org/api/ip
```

در Windows از `curl.exe` استفاده کنید. خروجی دستور ممکن است IP را نشان دهد؛ برای گزارش عمومی آن را حذف کنید. بسته مخصوص Chrome دسکتاپ است؛ برای اجرای معمولی Node.js لازم نیست. راهنمای نصب و اتصال در `guide.html` هم همراه بسته است.
