# روزن | Rozane

**یک افزونهٔ رایگان و متن‌باز برای اتصال سرویس‌های گوگل در Chrome به Tor محلی.**

روزن از یک مشکل واقعی شروع شد: Gemini با وجود روشن‌بودن VPN همچنان خطای دسترسی نشان می‌داد. این پروژه با کمک Codex توسعه پیدا کرد تا بتوان ترافیک وب سرویس‌های گوگل را از اتصال Tor روی همان کامپیوتر عبور داد.

نسخهٔ **۰.۴.۰** دسترسی سریع به **Gemini، Google Flow و Notebook** را در یک افزونه جمع می‌کند؛ همراه با رابط فارسی، کلید روشن/خاموش و آزمایش اتصال Tor.

**Tor Browser باید جداگانه نصب، باز و متصل باشد.** روزن خودش سرور، VPN یا شبکهٔ Tor را راه‌اندازی نمی‌کند و دسترسی دائمی یا نامحدود به سرویس‌های گوگل را تضمین نمی‌کند.

[گزارش مشکل و بازخورد](https://github.com/Grandudelife/Rozene/issues) · [راهنمای کامل نصب](guide.html) · [گزارش اعتبارسنجی](VALIDATION.md) · [مجوز MIT](LICENSE)

## چه امکاناتی دارد؟

- دکمهٔ جداگانه برای بازکردن Gemini، Flow و Notebook.
- هدایت دامنه‌های مشخص گوگل به پروکسی محلی Tor.
- پشتیبانی از آدرس قدیمی NotebookLM و لینک‌های Flow در `labs.google`.
- روشن و خاموش‌کردن مسیر از داخل افزونه.
- آزمایش اختیاری اتصال با سرویس رسمی Tor Project.
- تشخیص اینکه افزونهٔ دیگری کنترل پروکسی Chrome را در اختیار دارد.
- تنظیم پورت محلی و کپی گزارش وضعیت، بدون درج متن گفتگو، کوکی یا IP خروجی.
- رابط فارسی و راست‌چین با فونت محلی Vazirmatn.
- بدون مرحلهٔ build یا نصب وابستگی برای استفادهٔ معمولی.

## وضعیت آزمایش‌ها

| مورد | وضعیت |
| --- | --- |
| ورود به حساب و دریافت پاسخ Gemini روی Chrome مک | موفقیت نسخهٔ ۰.۳.۰ توسط کاربر گزارش شده است |
| مسیریابی Gemini، Flow، Notebook و دامنه‌های مرتبط در نسخهٔ ۰.۴.۰ | با آزمون خودکار بررسی شده است |
| استفادهٔ واقعی از Flow و Notebook با نسخهٔ ۰.۴.۰ | هنوز نیازمند تأیید کاربران است |
| Chrome روی ویندوز | بسته قابل نصب است؛ آزمایش عملی روی ویندوز هنوز انجام نشده است |
| آیفون و اندروید | این بسته نسخهٔ موبایل ندارد |

در آزمایش موفق اولیه، انتخاب یک گرهٔ خروجی مشخص Tor مؤثر بود. این نتیجه تضمین نمی‌کند همان گره یا اتصال برای همه و همیشه کار کند. تنظیم اختصاصی Tor کاربر داخل افزونه قرار ندارد.

**تأیید اتصال Tor فقط نشان می‌دهد درخواست آزمایشی از Tor گذشته است؛ موفقیت هر سرویس را باید با دریافت پاسخ یا تولید محتوای واقعی بررسی کرد.**

## پیش‌نیازها

1. Chrome دسکتاپ، نسخهٔ ۱۱۱ یا جدیدتر.
2. [Tor Browser از وب‌سایت رسمی](https://www.torproject.org/download/)، نصب‌شده روی همان دستگاه.
3. دسترسی به شبکهٔ Tor؛ بسته به شبکهٔ شما ممکن است پل Tor یا VPN موجودتان لازم باشد.
4. حساب گوگل و شرایط لازم برای سرویسی که می‌خواهید استفاده کنید.

خود روزن رایگان است. سهمیه‌ها، اعتبار تولید محتوا، اشتراک‌ها و شرایط حساب گوگل را تغییر نمی‌دهد.

## نصب روی مک و ویندوز

### ۱. دریافت فایل‌ها

در صفحهٔ همین مخزن، **Code → Download ZIP** را بزنید و فایل را استخراج کنید. در ویندوز می‌توانید از **Extract All** استفاده کنید.

پوشهٔ استخراج‌شده را در یک محل ثابت نگه دارید؛ Chrome فایل‌های افزونه را از همین محل می‌خواند.

### ۲. آماده‌کردن اتصال

- Tor Browser را باز کنید و منتظر بمانید اتصال کامل شود.
- اگر برای اتصال Tor از VPN استفاده می‌کنید، آن را متصل نگه دارید.
- نسخه‌های قبلی روزن و افزونه‌های کنترل‌کنندهٔ پروکسی مثل VeePN را غیرفعال کنید تا با روزن تداخل نداشته باشند.

### ۳. بارگذاری در Chrome

1. در نوار آدرس Chrome بنویسید: `chrome://extensions`
2. **Developer mode** را روشن کنید.
3. **Load unpacked** را بزنید.
4. پوشه‌ای را انتخاب کنید که فایل `manifest.json` مستقیماً داخل آن قرار دارد.
5. از منوی افزونه‌های Chrome، روزن را برای دسترسی راحت‌تر Pin کنید.

اگر خطای **Manifest file is missing or unreadable** دیدید، پوشهٔ انتخاب‌شده را بررسی کنید. باید پوشهٔ حاوی `manifest.json` را انتخاب کنید؛ خود ZIP یا پوشهٔ والد آن مناسب نیست.

### ۴. فعال‌سازی

1. پنجرهٔ روزن را باز کنید.
2. پورت پیش‌فرض را روی `9150` نگه دارید، مگر اینکه پورت Tor خود را تغییر داده باشید.
3. **فعال‌کردن مسیر Tor** را بزنید.
4. **آزمایش اتصال Tor** را اجرا کنید.
5. پس از تأیید، سرویس موردنظر را از دکمه‌های افزونه باز کنید.

میزبان `127.0.0.1` به کامپیوتر خود شما اشاره می‌کند. Tor روی دستگاه فرد دیگری، اتصال روزن شما را تأمین نمی‌کند.

## استفادهٔ روزانه

بعد از روشن‌کردن کامپیوتر:

1. اتصال اینترنت و در صورت نیاز VPN را برقرار کنید.
2. Tor Browser را باز و متصل کنید.
3. Chrome را باز کنید و اگر روزن خاموش است، آن را روشن کنید.
4. اتصال Tor را آزمایش و سرویس موردنظر را باز کنید.

**Tor Browser باید در زمان استفاده باز بماند.** کوچک‌کردن پنجره مشکلی ندارد، اما خروج کامل از برنامه اتصال را قطع می‌کند. برای پایان استفاده، ابتدا مسیر روزن را خاموش و سپس Tor را ببندید.

نیازی به نصب مجدد افزونه یا ویرایش روزانهٔ تنظیمات Tor نیست.

## ارتقا از نسخهٔ قبلی

1. در روزن قبلی، **خاموش‌کردن مسیر Tor** را بزنید.
2. افزونهٔ قبلی را در `chrome://extensions` غیرفعال کنید.
3. نسخهٔ جدید را در پوشه‌ای جداگانه استخراج و با **Load unpacked** بارگذاری کنید.
4. نسخهٔ جدید را فعال و اتصال را آزمایش کنید.

تنظیم موفق Tor یا VPN خود را بی‌دلیل تغییر ندهید. برای آزمایش مستقل Flow، افزونهٔ اختصاصی قبلی Flow را هم موقتاً خاموش کنید.

## رفع خطاهای رایج

| وضعیت | اقدام پیشنهادی |
| --- | --- |
| کنترل پروکسی در اختیار روزن نیست | افزونه‌های دیگر پروکسی را غیرفعال کنید. روی دستگاه سازمانی، سیاست مدیر سیستم هم ممکن است مانع باشد. |
| آزمایش اتصال کامل نشد | بازبودن و اتصال Tor، پورت محلی و دسترسی به سرویس بررسی را کنترل کنید. |
| خطای Connection refused | ورودی محلی Tor روی پورت انتخاب‌شده در دسترس نیست. |
| Tor تأیید می‌شود ولی سرویس خطای 403 یا 1060 می‌دهد | تأیید Tor به معنای پذیرش اتصال توسط گوگل نیست. تب تازه باز کنید و وضعیت خروجی Tor و شرایط حساب را بررسی کنید. |
| Tor Browser کار می‌کند ولی Chrome خطا می‌دهد | این دو مرورگر ممکن است از مدارها و خروجی‌های متفاوت Tor استفاده کنند. |
| مقدار `check` در گزارش خالی است | نتیجهٔ آزمایش در حافظهٔ موقت سرویس پس‌زمینه نگه‌داری می‌شود و ممکن است پاک شود؛ آزمایش را دوباره اجرا کنید. |
| پس از بستن Tor، بعضی سایت‌های گوگل باز نمی‌شوند | روزن را خاموش کنید یا Tor را دوباره متصل کنید. |
| فایل‌ها یا ویدیوها کند بارگذاری می‌شوند | سرعت شبکهٔ Tor متغیر است؛ روزن تضمین افزایش سرعت ندارد. |

برای تنظیم ورودی محلی Tor در مک و توضیح آزمایش اختیاری خروجی مشخص، فایل **[guide.html](guide.html)** را پس از دانلود در مرورگر باز کنید. گیت‌هاب ممکن است خودِ کد HTML را نشان دهد.

### آزمایش دستی اتصال

در Terminal مک:

</div>

```bash
curl -q --noproxy '' --proxy socks5h://127.0.0.1:9150 --connect-timeout 5 --max-time 20 --fail --silent --show-error https://check.torproject.org/api/ip
```

<div dir="rtl">

در PowerShell ویندوز:

</div>

```powershell
curl.exe -q --proxy socks5h://127.0.0.1:9150 --connect-timeout 5 --max-time 20 --fail --silent --show-error https://check.torproject.org/api/ip
```

<div dir="rtl">

وجود `"IsTor":true` یعنی این درخواست از Tor عبور کرده است. خروجی ممکن است IP خروجی Tor را هم نمایش دهد؛ برای گزارش مشکل نیازی به انتشار آن نیست.

فایل `Check-Tor.command` ابزار کمکی مک است و برای نصب روی ویندوز لازم نیست. هیچ‌کدام از این آزمایش‌ها تنظیمات سیستم را تغییر نمی‌دهند.

## دامنهٔ اثر افزونه

این دامنه‌ها و زیردامنه‌هایشان از Tor عبور می‌کنند:

- `google.com`
- `googleapis.com`
- `gstatic.com`
- `googleusercontent.com`
- `ggpht.com`

همچنین این سه میزبان دقیقاً پوشش داده می‌شوند:

- `labs.google`
- `accounts.youtube.com`
- `check.torproject.org`

بنابراین اثر روزن فقط به سه دکمهٔ داخل افزونه محدود نیست؛ Gmail، Drive و منابع گوگل در سایت‌های دیگر هم ممکن است تحت‌تأثیر قرار بگیرند.

برای مقصدهای انتخاب‌شده، مسیر مستقیم جایگزین تعریف نشده است. سایر مقصدها در تنظیم پروکسی روزن `DIRECT` هستند؛ VPN در سطح سیستم همچنان می‌تواند روی آن‌ها اثر داشته باشد، اما قواعد پروکسی قبلی سیستم برای آن‌ها از این مسیر اعمال نمی‌شود.

روزن در حالت Incognito فعال نمی‌شود و همهٔ ترافیک دستگاه، WebRTC یا تمام دامنه‌های احتمالی آیندهٔ گوگل را پوشش نمی‌دهد.

## حریم خصوصی و مجوزها

روزن مجوز خواندن متن صفحات، کوکی‌ها، رمزها یا تاریخچهٔ مرورگر را درخواست نمی‌کند. پاسخ‌های گوگل را دست‌کاری نمی‌کند و گواهی نصب نمی‌کند.

| مجوز | کاربرد |
| --- | --- |
| `proxy` | تنظیم مسیر دامنه‌های انتخاب‌شده به Tor محلی |
| `storage` | ذخیرهٔ پورت انتخاب‌شده |
| دسترسی به `check.torproject.org` | آزمایش اختیاری اتصال Tor |

سرویس بررسی Tor، IP خروجی درخواست را می‌بیند، اما روزن آن را در گزارش وضعیت نگه نمی‌دارد. در کد افزونه سرویس تحلیل رفتار یا ارسال گزارش به سرور اختصاصی پروژه وجود ندارد.

**اتصال Chrome به Tor، محافظت‌های ناشناس‌ماندن Tor Browser را به Chrome اضافه نمی‌کند.** هدف این پروژه هدایت اتصال است. [توضیح رسمی پروژهٔ Tor](https://support.torproject.org/tor-browser/security/using-tor-with-other-browsers/)

## اشتراک‌گذاری با دوستان

می‌توانید همین مخزن یا بستهٔ افزونه را با حفظ مجوز MIT به دیگران بدهید. هر نفر باید Tor را روی دستگاه خودش راه‌اندازی و با حساب خودش وارد سرویس‌ها شود.

برای اشتراک‌گذاری، فایل‌های پروژه کافی‌اند؛ پروفایل Chrome، کوکی‌ها، رمزها یا کانفیگ خصوصی VPN خود را ارسال نکنید.

## توسعه و مشارکت

افزونه با JavaScript و Manifest V3 ساخته شده و برای اجرا به build نیاز ندارد. برای اجرای آزمون‌ها، Node.js با پشتیبانی از `node:test` لازم است:

</div>

```bash
node --test tests/*.test.cjs
```

<div dir="rtl">

در نسخهٔ ۰.۴.۰، هر ۱۴ آزمون مسیریابی، اعتبارسنجی پورت، کنترل پروکسی و رفتار آزمایش اتصال پاس شده‌اند. این آزمون‌ها جای بررسی عملی روی مرورگر و سرویس واقعی را نمی‌گیرند.

| فایل | مسئولیت |
| --- | --- |
| `manifest.json` | مشخصات افزونه و مجوزها |
| `core.js` | قواعد مسیریابی PAC و اعتبارسنجی پورت |
| `background.js` | کنترل پروکسی و آزمایش اتصال |
| `popup.html` و `popup.js` | رابط و رفتار پنجرهٔ افزونه |
| `style.css` و `assets/` | ظاهر، فونت و آیکون‌ها |
| `guide.html` | راهنمای فارسی نصب و رفع خطا |
| `tests/proxy.test.cjs` | آزمون‌های خودکار |

برای [ثبت Issue](https://github.com/Grandudelife/Rozene/issues)، نام سیستم‌عامل، نسخهٔ Chrome و روزن، سرویس موردنظر، متن خطا و مراحل تکرار مشکل را بنویسید. گزارش وضعیت افزونه هم می‌تواند کمک کند. کوکی، توکن، رمز یا فایل کامل HAR را در Issue عمومی قرار ندهید.

Pull Request برای رفع اشکال، بهبود راهنما و دسترس‌پذیری، یا افزودن آزمون‌های کاربردی خوش‌آمد است. تغییرات مسیریابی را همراه با آزمون مرز دامنه‌ها و بررسی نبود مسیر مستقیم جایگزین ارائه کنید.
