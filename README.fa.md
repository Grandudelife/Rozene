# روزن ۰.۴.۰ — Gemini، Flow و Notebook

راهنمای فارسی راست‌چین: guide.html را باز کنید.

- همین ZIP برای Chrome دسکتاپ روی مک و ویندوز است؛ Tor Browser باید جداگانه روی هر دستگاه نصب و متصل باشد.
- نسخهٔ قبلی روزن را خاموش و غیرفعال کنید؛ ZIP را استخراج، پوشه را در محل ثابت نگه دارید و از chrome://extensions با Developer mode و Load unpacked نصب کنید.
- پورت پیش‌فرض 9150 است. روزن را روشن و اتصال Tor را آزمایش کنید؛ سپس دکمهٔ سرویس را بزنید.
- تنظیم موفق فعلی Tor و VPN را تغییر ندهید. فایل torrc یا تنظیم خروجی شما داخل این ZIP نیست. روش اختیاری تکرار آزمایش موفق و بازگشت آن در راهنما آمده است.
- نسخهٔ ۰.۳.۰ طبق گزارش کاربر با حساب شخصی در کروم مک برای Gemini موفق بوده است. Flow، Notebook و ویندوز هنوز تأیید عملی نشده‌اند.
- افزونه رایگان و قابل ارسال تحت MIT است؛ سهمیه و امکانات پولی سرویس‌ها تغییر نمی‌کنند. این بسته کد یا سرویس افزونهٔ تجاری Flow را شامل نمی‌شود.
- بدون حساب، کوکی، رمز، متن گفتگو، کلید VPN یا پروفایل شخصی. برای اشتراک‌گذاری فقط همین بسته را بفرستید.
- سایر دامنه‌های اصلی گوگل مثل Gmail/Drive هم از Tor عبور می‌کنند؛ labs.google اضافه شده است. مقصدهای دیگر DIRECT هستند و VPN سیستم همچنان اثر دارد. برای مقصدهای انتخاب‌شده fallback مستقیم تعریف نشده است.
- Chrome از این طریق محافظت‌های ناشناس‌ماندن Tor Browser را به دست نمی‌آورد. نسخهٔ موبایل در این بسته نیست.
- نتیجهٔ آزمایش اتصال با خاموش‌شدن سرویس پس‌زمینه ممکن است پاک شود؛ آزمایش را دوباره بزنید.

## توسعه
بدون build یا وابستگی. آزمون: node --test tests/*.test.cjs
Check-Tor.command فقط ابزار تشخیص مک است؛ برای ویندوز لازم نیست. دستور ویندوز در guide.html آمده است.
